### What I'm running

**[sitecheck](https://github.com/aleksandersarkezi/sitecheck)** grades how well a website is
protected, from A to F. It runs on my own Hetzner server in Docker behind Caddy, deploys
itself from GitHub Actions with automatic rollback, and alerts me on Discord when a site
gets worse. [Try it](https://sitecheck.aleksandersarkezi.com)

**[netscan](https://github.com/aleksandersarkezi/netscan)** is an async network scanner for
the command line: TCP scans without root, banner grabbing, export to JSON, CSV or XML.
